    - **학습 환류** — 관제요원의 정탐/오탐 판정이 학습 데이터셋으로 자동 환류되어 AI 정확도를 지속적으로 개선합니다.

### VLM 기반 재난 영상분석 플랫폼 (DH-Aegis)

- **개발 기간** : 2026.04 ~ 2026.07
- **사용 기술** : `Python` `FastAPI` `PyTorch` `Transformers` `PEFT(LoRA)` `bitsandbytes` `Qwen3-VL` `Gemma-3` `Spring MVC` `Spring Security` `MyBatis` `PostgreSQL` `PostGIS`
- **시스템 설명** : 현장 CCTV 스틸컷 이미지를 VLM으로 해석하여 NDMS 표준 경보코드(ALMCODE 5단계)로 위험 등급을 부여하고, 표준화된 재난 이벤트로 저장·관제하며 외부 재난통합플랫폼에 Open API로 연계하는 플랫폼입니다.
    - **2-서버 책임 분리** — GPU 추론 서버(FastAPI)와 관제 플랫폼(Spring)을 분리하여, 추론 서버는 해석만 수행하고 위험 등급 산정은 플랫폼이 표준 코드로만 부여하도록 책임을 나누었습니다.
    - **추론 자원 관리** — Qwen3-VL-8B 상주 추론, VRAM 예산 기반 LRU 모델 축출, 세마포어 동시성 제어와 대기 큐 백프레셔를 구현했습니다.
    - **수집 · 연계** — 폴더 감시 기반 수집 파이프라인과 서명 기반 콜백 연계를 구축했습니다.
    - **파인튜닝 환류 체계** — 관제요원 라벨링 → 데이터셋 → LoRA 이어학습 → 어댑터 배포·롤백으로 이어지는 환류 체계를 구현했습니다.
    - **완료 판정기(하네스)** — 응답 파싱 성공 여부만 보던 완료 판정을 보완하기 위해, 관측소 실측 등급과 AI 판정을 대조하는 완료 판정기(하네스)와 재시도 루프를 설계·구현하여 미탐(MISSED)·오탐(FALSE_ALARM)을 자동으로 검출합니다.
    - **자기 채점 오염 차단** — 판정 검증을 결정론적 규칙으로 고정하여 모델이 자기 출력을 스스로 채점하는 오염을 차단했습니다. 재시도 루프는 인프라 장애 경로에만 좁게 두어, 판정 오류가 학습 정답을 오염시키지 않도록 설계했습니다.
- **담당 역할** : 개발PM, 설계(기능정의, 화면설계, DB설계, API 계약 설계, 판정 품질 검증 체계 설계), VLM 추론 서버 개발, 완료 판정기(하네스)·재시도 루프 구현, 프론트엔드+백엔드 개발

### CCTV 자동 진단 및 모니터링 플랫폼 (DH-Watchive-Check)

- **개발 기간** : 2026.01 ~ 2026.03
- **사용 기술** : `Spring MVC` `JavaScript` `JSP` `PostgreSQL` `PostGIS`
- **시스템 설명** : 지방자치단체에 설치된 CCTV 카메라의 상태를 자동으로 진단하고 장애를 탐지·분류·복구하는 NOC(Network Operations Center) 시스템입니다.
